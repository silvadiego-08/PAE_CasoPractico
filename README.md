# Sistema de Gestión de Solicitudes de Clientes

**Asignatura:** Programación de Aplicaciones de Escritorio  
**Profesor:** Jose Duran

## Propósito
Desarrollar una aplicación de escritorio utilizando JavaFX, Scene Builder e IntelliJ IDEA, aplicando controles gráficos, eventos, navegación entre ventanas y paso de información entre formularios.

## Contexto del Caso Práctico
Una empresa requiere una aplicación de escritorio para realizar el registro y consulta de solicitudes de sus clientes. El sistema permite registrar información básica de un cliente y generar una solicitud asociada. La aplicación está estructurada para permitir la navegación fluida entre formularios y la transferencia de información compartida de manera eficiente y segura.
